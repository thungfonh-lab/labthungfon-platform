1. ภาพรวมระบบ
================================================================================

labthungfon Platform คือระบบจัดการตารางเวรบุคลากรทางการแพทย์
พัฒนาเพื่อใช้งานภายในห้องปฏิบัติการ/ห้องยา สามารถ:

  - จัดตารางเวรอัตโนมัติตามอัลกอริทึมที่กำหนด
  - บันทึกและคำนวณค่าตอบแทนนอกเวลาราชการ (On-Call)
  - สร้างรายงานในรูปแบบต่าง ๆ (Excel / Word) ได้ทันที
  - จัดการสิทธิ์ผู้ใช้งานแบบ Role-Based Access Control (RBAC)
  - แจ้งเตือนผ่าน Email และ LINE Notify
  - สำรองข้อมูลอัตโนมัติทุกวัน และล้าง Audit Log อัตโนมัติทุกสัปดาห์

--------------------------------------------------------------------------------
1.1 สถาปัตยกรรมระบบ
--------------------------------------------------------------------------------

  ส่วนหน้าบ้าน (Frontend)  : Google Apps Script HTML ไฟล์ (gas-src/*.html)
                               เรียก REST API ผ่าน fetch()
  ส่วนหลังบ้าน (Backend)   : Node.js / Express API บน Vercel Serverless Functions
  ฐานข้อมูล                : Google Sheets (ผ่าน Google Sheets API v4)
  การยืนยันตัวตน           : JWT (JSON Web Token) มีอายุ 8 ชั่วโมง
  การแจ้งเตือน             : Email (SMTP) และ LINE Notify
  สำรองข้อมูล              : Snapshot JSON เก็บใน Google Sheets sheet ชื่อ 'Backups'

--------------------------------------------------------------------------------
1.2 Sheets (แผ่นงาน) ในระบบ
--------------------------------------------------------------------------------

  Users          - ข้อมูลผู้ใช้งานและรหัสผ่าน
  Roles          - นิยาม Role (admin, supervisor, staff ฯลฯ)
  Permissions    - Matrix สิทธิ์การใช้งานแต่ละ Role
  MasterData     - เจ้าหน้าที่, จุดปฏิบัติงาน, ประเภทเวร, อัตราพิเศษ
  Transactions   - บันทึก On-Call, Availability, ตารางเวร
  Schedules      - ผลลัพธ์การจัดตารางเวรรายเดือน
  ReportsCache   - Cache รายงานเพื่อเพิ่มความเร็ว
  AuditLogs      - บันทึกการกระทำสำคัญทุกครั้ง
  Settings       - ค่าตั้งต้นระบบ อัตราค่าตอบแทน
  Backups        - Snapshot สำรองข้อมูล (สร้างอัตโนมัติ)

3. การติดตั้งครั้งแรก (First-Time Setup)
================================================================================

--------------------------------------------------------------------------------
3.1 สร้าง Google Cloud Service Account
--------------------------------------------------------------------------------

Service Account คือบัญชีที่ระบบใช้ในการเข้าถึง Google Sheets แทนผู้ใช้งาน

  1. เปิด https://console.cloud.google.com และเข้าสู่ระบบด้วยบัญชี Google
  2. สร้าง Project ใหม่ หรือเลือก Project ที่มีอยู่แล้ว
  3. ไปที่ APIs & Services > Library > ค้นหา 'Google Sheets API' > คลิก Enable
  4. ไปที่ IAM & Admin > Service Accounts > Create Service Account
  5. ตั้งชื่อ เช่น labthungfon-api > คลิก Create and Continue > Done
  6. คลิกที่ Service Account ที่สร้าง > แท็บ Keys > Add Key > Create new key > JSON > Download
  7. จะได้ไฟล์ .json เก็บไว้อย่างปลอดภัย ห้ามอัปโหลด Git หรือแชร์กับผู้อื่น

--------------------------------------------------------------------------------
3.2 สร้าง Google Spreadsheet
--------------------------------------------------------------------------------

  1. สร้าง Google Spreadsheet ใหม่ที่ https://sheets.google.com
  2. จดบันทึก Spreadsheet ID จาก URL:
       https://docs.google.com/spreadsheets/d/[SPREADSHEET_ID]/edit
  3. คลิก Share > เพิ่ม Email ของ Service Account (จากไฟล์ JSON ที่ field client_email)
     > ให้สิทธิ์ Editor

  [!] หากไม่ Share ให้ Service Account ระบบจะไม่สามารถอ่านหรือเขียนข้อมูลได้

--------------------------------------------------------------------------------
3.3 ดาวน์โหลดโค้ดและติดตั้ง Dependencies
--------------------------------------------------------------------------------

  1. Clone หรือดาวน์โหลด Repository มาเก็บในเครื่อง
  2. เปิด Terminal แล้วเข้าไปที่โฟลเดอร์โปรเจกต์:
       cd 'labthungfon platform'
  3. ติดตั้ง Node.js packages:
       npm install

--------------------------------------------------------------------------------
3.4 ตั้งค่า Environment Variables (.env)
--------------------------------------------------------------------------------

สร้างไฟล์ .env จาก .env.example:
  cp .env.example .env

แล้วกรอกค่าต่อไปนี้:

  GOOGLE_SERVICE_ACCOUNT_KEY  - เนื้อหา JSON ของ Service Account Key ทั้งหมดในบรรทัดเดียว
  GOOGLE_SHEETS_ID            - Spreadsheet ID ที่สร้างในขั้นตอน 3.2
  JWT_SECRET                  - สตริงสุ่มยาว เช่น: openssl rand -hex 32
  CRON_SECRET                 - สตริงสุ่มยาวอีกชุด (ใช้ป้องกัน Cron endpoint)
  CORS_ORIGIN                 - * (ใช้งานทุก Origin) หรือระบุ URL ที่อนุญาต
  MAIL_HOST / MAIL_PORT ฯลฯ  - ข้อมูล SMTP Server (ไม่บังคับ)
  LINE_TOKEN                  - LINE Notify Token (ไม่บังคับ)

วิธีแปลง Service Account JSON เป็นบรรทัดเดียว:
  node -e "console.log(JSON.stringify(require('./your-key-file.json')))"

[!] ห้ามใส่ไฟล์ .env หรือไฟล์ key JSON ใน Git เด็ดขาด — มีการป้องกันใน .gitignore แล้ว

--------------------------------------------------------------------------------
3.5 ตั้งค่าฐานข้อมูลครั้งแรก (runFullSetup)
--------------------------------------------------------------------------------

วิธีที่ 1: ผ่าน Google Apps Script (แนะนำ)

  1. เปิด Spreadsheet > Extensions > Apps Script
  2. อัปโหลดโค้ดจากโฟลเดอร์ gas-src/ ด้วย clasp:
       cd gas-src
       clasp push
  3. ใน Apps Script Editor เลือกฟังก์ชัน runFullSetup แล้วคลิก Run
  4. อนุญาต OAuth scopes ที่ระบบขอ (Sheets, Drive)
  5. รอจนเสร็จ — จะเห็น Sheet ทั้ง 9 แผ่นถูกสร้าง

วิธีที่ 2: ผ่าน API Endpoint (หากติดตั้ง Backend แล้ว)
  POST /api/setup/init

--------------------------------------------------------------------------------
3.6 สร้างผู้ใช้ Admin คนแรก
--------------------------------------------------------------------------------

  1. ใน Apps Script Editor เลือกฟังก์ชัน seedAdminUser แล้วแก้ไข:
       seedAdminUser('admin@hospital.go.th', 'TemporaryPass@123')
  2. คลิก Run — รอจนเสร็จ
  3. ลบหรือ Comment บรรทัดนั้นออกทันทีหลังใช้งาน ห้ามเก็บรหัสผ่านไว้ในโค้ด
  4. Login ด้วย Admin แล้วเปลี่ยนรหัสผ่านผ่าน Sheet Users โดยตรง (ดูหัวข้อ 5.3)

--------------------------------------------------------------------------------
3.7 Deploy บน Vercel
--------------------------------------------------------------------------------

  1. Login Vercel CLI:
       vercel login
  2. Deploy ไปยัง Production:
       vercel --prod
  3. หรือใช้ Vercel Dashboard: Import Git Repository แล้วกด Deploy
  4. ไปที่ Settings > Environment Variables > เพิ่มค่าจาก .env ทุกตัว

  [!] GOOGLE_SERVICE_ACCOUNT_KEY ต้องวางเป็นบรรทัดเดียว ไม่ใช่ JSON หลายบรรทัด

  5. หลัง Deploy จะได้ URL เช่น https://labthungfon-platform.vercel.app
  6. แก้ไขไฟล์ gas-src/index.html ให้ meta tag api-url ชี้ไปยัง URL นั้น

--------------------------------------------------------------------------------
3.8 Deploy Google Apps Script (Frontend)
--------------------------------------------------------------------------------

  1. ใน Apps Script Editor: Deploy > New deployment > Web app
  2. Execute as: User accessing the web app
  3. Who has access: Anyone within [Workspace domain ของคุณ]
  4. คัดลอก Web App URL แจกจ่ายให้เจ้าหน้าที่

4. คำแนะนำการใช้งานระบบ
================================================================================

--------------------------------------------------------------------------------
4.1 การ Login
--------------------------------------------------------------------------------

  เปิด Web App URL > กรอก Email และรหัสผ่าน > คลิก เข้าสู่ระบบ
  Session มีอายุ 8 ชั่วโมง หลังจากนั้นระบบจะ Logout อัตโนมัติ

--------------------------------------------------------------------------------
4.2 เมนูหลัก
--------------------------------------------------------------------------------

  ตารางเวร        - จัดการตารางเวรรายเดือน: Setup / Collect / Grid / Reports
  On-Call / OT    - บันทึกการปฏิบัติงานนอกเวลา และดูรายงาน OT
  สมดุลเวร        - ตรวจสอบชั่วโมงสะสมของแต่ละคน
  ผู้ดูแลระบบ     - จัดการผู้ใช้, สิทธิ์, Master Data, ตั้งค่าระบบ
  ออกจากระบบ      - ยกเลิก Session (Token หมดอายุเองใน 8 ชม.)

--------------------------------------------------------------------------------
4.3 การจัดตารางเวรรายเดือน
--------------------------------------------------------------------------------

  1. ไปที่ ตารางเวร > Setup — กำหนดเดือน/ปี, ตรวจสอบข้อมูล Availability
  2. คลิก สร้างตารางเวร — ระบบคำนวณอัตโนมัติ (ใช้เวลาประมาณ 10-30 วินาที)
  3. ตรวจสอบผลลัพธ์ใน Grid — แก้ไข Override หากต้องการ
  4. คลิก บันทึก เพื่อ Save ลงฐานข้อมูล
  5. คลิก เผยแพร่ (Publish) เมื่อพร้อม — เจ้าหน้าที่จะเห็นตารางนี้

  [!] ขณะ Generate ระบบล็อกเดือนนั้นไว้ ผู้ใช้คนอื่นต้องรอจนเสร็จก่อน (~20 วินาที)

5. การดูแลรักษาระบบ
================================================================================

--------------------------------------------------------------------------------
5.1 การสำรองข้อมูล (Backup)
--------------------------------------------------------------------------------

ระบบสำรองข้อมูลอัตโนมัติ ทุกวัน เวลา 02:00 น. (เวลาไทย) โดย Vercel Cron Job
Backup เก็บเป็น JSON Snapshot ใน Sheet 'Backups' (เก็บ 14 ครั้งล่าสุด)

  การ Backup ด้วยตนเอง:
    ไปที่ ตั้งค่า > สำรองข้อมูล & Audit Log > คลิก 'สำรองข้อมูลตอนนี้'

  การดาวน์โหลด Backup:
    ในหน้าเดียวกัน จะเห็นรายการ Backup พร้อมวันเวลา คลิก ดาวน์โหลด

  การ Restore จาก Backup (ทำด้วยตนเอง):
    1. ดาวน์โหลดไฟล์ .json ที่ต้องการ Restore
    2. เปิด Spreadsheet > ค้นหา Sheet ที่ต้องการ Restore
    3. นำข้อมูลจาก JSON วางลงใน Sheet ที่ถูกต้อง

  [!] แนะนำให้ทดสอบ Restore ใน Spreadsheet สำรองก่อน เพื่อป้องกันข้อมูลสูญหาย

--------------------------------------------------------------------------------
5.2 Audit Log
--------------------------------------------------------------------------------

ระบบบันทึก Action สำคัญทุกครั้งลงใน Sheet 'AuditLogs'
Audit Log ถูกลบอัตโนมัติทุกสัปดาห์ โดยเก็บไว้เพียง 90 วันล่าสุด

  การดู Audit Log:
    ไปที่ ผู้ดูแลระบบ > Audit Log — กรองตาม User, Module, Action, วันที่

  การปรับระยะเวลาเก็บ Log:
    ตั้งค่า > สำรองข้อมูล & Audit Log > ใส่จำนวนวัน > คลิก ล้าง Log เก่า

--------------------------------------------------------------------------------
5.3 การจัดการผู้ใช้งาน
--------------------------------------------------------------------------------

  เพิ่มผู้ใช้ใหม่    : ผู้ดูแลระบบ > ผู้ใช้งาน > เพิ่มผู้ใช้
  เปลี่ยนรหัสผ่าน   : ผู้ดูแลระบบ > ผู้ใช้งาน > Reset Password
  ปิดใช้งาน Account : คลิก Deactivate (Token เก่ายังใช้ได้ถึง 8 ชม.)
  สิทธิ์ผู้ใช้       : ผู้ดูแลระบบ > สิทธิ์ — กำหนด Role และ Permission Override

--------------------------------------------------------------------------------
5.4 การ Deploy โค้ดใหม่
--------------------------------------------------------------------------------

  Backend (Vercel API) — Deploy อัตโนมัติเมื่อ Push ไปยัง Branch หลัก:
    git add -A
    git commit -m 'รายละเอียดการเปลี่ยนแปลง'
    git push origin main

  Frontend (Google Apps Script):
    [!] ทุกครั้งก่อน push ให้ clasp pull ก่อนเสมอ เพราะอาจมีการแก้ไขจาก
        Apps Script Editor โดยตรง

    cd gas-src
    clasp pull
    clasp push
    clasp deploy    # สร้าง Version ใหม่ให้ Production URL อัปเดต

  [!] clasp push อัปเดตเฉพาะ HEAD (Test deployment) เท่านั้น
      ต้องรัน clasp deploy ด้วยเพื่อให้ Production URL อัปเดต

--------------------------------------------------------------------------------
5.5 การตรวจสอบ Cron Jobs
--------------------------------------------------------------------------------

Vercel Dashboard > Settings > Cron Jobs — ดูสถานะ Job ล่าสุด 2 รายการ:

  daily backup (02:00 ทุกวัน)       : /api/cron/backup
  weekly audit-purge (อาทิตย์ 02:00): /api/cron/audit-purge

  หาก Cron Job ล้มเหลว สามารถรัน Manual จาก ตั้งค่า ในระบบแทน

6. การแก้ปัญหาเบื้องต้น
================================================================================

--------------------------------------------------------------------------------
6.1 Login ไม่ได้
--------------------------------------------------------------------------------

  'อีเมลหรือรหัสผ่านไม่ถูกต้อง'
    → ตรวจสอบ Email ใน Sheet 'Users' และ column 'active' ว่าเป็น TRUE

  'Session หมดอายุ'
    → Login ใหม่ — Session อายุ 8 ชั่วโมงเท่านั้น

  หน้าเว็บขึ้น Error 500
    → ตรวจสอบ Environment Variables ใน Vercel ครบหรือไม่

--------------------------------------------------------------------------------
6.2 Generate ตารางเวรช้า / ค้าง
--------------------------------------------------------------------------------

  - ปกติใช้เวลา 10-30 วินาที ถ้านานกว่านั้นอาจมี Lock ค้างอยู่
  - ตรวจสอบ Sheet 'Settings' หา Row ที่ key เริ่มต้นด้วย lock_
    ถ้ามีค่าอยู่นานกว่า 1 นาที ให้ลบค่าใน Column value ออก
  - รีเฟรชหน้าเว็บแล้วลองใหม่

--------------------------------------------------------------------------------
6.3 ระบบไม่ส่ง Email / LINE
--------------------------------------------------------------------------------

  Email ไม่ส่ง  → ตรวจสอบ MAIL_HOST, MAIL_PORT, MAIL_USER, MAIL_PASS ใน Vercel
  LINE ไม่ส่ง   → ตรวจสอบ LINE_TOKEN ใน Vercel หรือ lineToken ใน Settings Sheet
  SMTP Error    → ลอง MAIL_PORT=465 และ MAIL_SECURE=true สำหรับ Gmail SMTP

--------------------------------------------------------------------------------
6.4 API ตอบกลับ 401 / 403
--------------------------------------------------------------------------------

  401 — Token หมดอายุหรือไม่ถูกต้อง ให้ Login ใหม่
  403 — ผู้ใช้ไม่มีสิทธิ์ ให้ Admin ตรวจสอบ Permissions ใน Sheet 'Permissions'

--------------------------------------------------------------------------------
6.5 ข้อมูลใน Sheet ไม่อัปเดต
--------------------------------------------------------------------------------

  - ตรวจสอบว่า Service Account มีสิทธิ์ Editor ใน Spreadsheet
  - ตรวจสอบ GOOGLE_SHEETS_ID ใน Vercel ว่าถูกต้อง
  - ดู Vercel Function Logs: Dashboard > Deployments > Functions

--------------------------------------------------------------------------------
6.6 เพิ่ม Environment Variable ใหม่
--------------------------------------------------------------------------------

  1. Vercel Dashboard > Project Settings > Environment Variables
  2. คลิก Add Variable > กรอก Key และ Value > Save
  3. Redeploy โปรเจกต์: Deployments > Redeploy

  [ ]  ไฟล์ .env และ Key JSON ไม่อยู่ใน Git
